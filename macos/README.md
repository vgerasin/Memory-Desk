Он сверен только глазами и простым тестом (`tests/test_stage11.py::test_macos_draft_is_consistent`: разбор `Info.plist`, парность скобок, нужные файлы). Считайте это заготовкой, которую надо один раз собрать и поправить по сообщениям компилятора.

## Что внутри

- `Sources/MemoryDesk/main.swift`, `AppDelegate.swift` — приложение (значок в Dock и в строке меню), главное меню с ⌘C/⌘V/⌘A/⌘Q, адрес `memorydesk://` (`open`, `today`, `scan`).
- `Server.swift` — находит папку программы (спрашивает один раз), запускает тот же `meeting-assistant`, что и `start.command`, ждёт `/api/health`, при выходе останавливает **только** тот сервер, который запустило само (чужой, запущенный из Терминала, не трогает).
- `WebWindow.swift` — окно с тем же интерфейсом (WKWebView): внешние ссылки и `obsidian://` открываются снаружи, файлы (PDF, DOCX, экспорт) скачиваются в «Загрузки», выбор файла для вложений, окна подтверждения.
- `StatusMenu.swift` — значок в строке меню: состояние обработки («Идёт обработка», «Ждут внимания: N»), «Открыть Memory Desk», «Обработать новые записи», «Выйти».
- `build_app.sh` + `Resources/Info.plist` — сборка `build/MemoryDesk.app` с подписью «ad hoc».
- `SHORTCUTS.md` — рецепты для «Быстрых команд».

## Как собрать

```
cd macos
zsh build_app.sh
```

Нужны Xcode или Command Line Tools (`xcode-select --install`). Результат — `macos/build/MemoryDesk.app`; перетащите в «Программы». Первый запуск: правый клик → «Открыть» (приложение не нотаризовано). При первом запуске приложение спросит папку программы (где лежит `meeting-assistant`).

## Чек-лист проверки (для вас)

1. `zsh build_app.sh` собирается без ошибок. Если компилятор ругается — пришлите текст, поправлю.
2. Двойной клик: появляется окно, сервер стартует, открывается интерфейс. Лог запуска — `logs/app.log` в папке программы.
3. Закрытие окна не останавливает работу (значок остаётся в строке меню); значок в Dock возвращает окно; «Выйти» останавливает сервер (`lsof -i :8502` пусто).
4. Если сервер уже запущен из `start.command`, приложение подключается к нему и при выходе его не гасит.
5. ⌘C, ⌘V, ⌘A, ⌘Z работают в полях; ссылки на внешние сайты открываются в браузере; «Открыть в Obsidian» работает.
6. Скачивание документа (PDF/DOCX) кладёт файл в «Загрузки».
7. Вложение (кнопка выбора файла) открывает системный диалог.
8. `open memorydesk://scan` в Терминале запускает обработку (при включённом PIN — открывает окно).
9. Значок в строке меню меняется, когда идёт обработка.

## Что осталось за этим черновиком

- **Подпись Developer ID и нотаризация** (нужен платный аккаунт Apple Developer): без них macOS при первом запуске просит открыть вручную.
- **Автообновление** приложения и «чистая установка без Терминала»: приложение пока опирается на уже установленную папку программы, `install.command` остаётся.
- **App Intents** для «Быстрых команд» (см. `SHORTCUTS.md`), быстрая заметка и закладка из строки меню, «Спросить архив» маленьким окном, «ближайшая встреча»: нужны вызовы API с аргументами и сборка в Xcode.
- Значка `.icns` нет: приложение пока с обычным значком.
