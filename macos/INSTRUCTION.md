# Как собрать приложение Memory Desk для macOS

Пошаговая инструкция. Занимает 10–15 минут, большую часть из них — установка средств разработчика, если их ещё нет.

> **Важно.** Код оболочки (`macos/`) написан без Mac, но на вашем Mac он уже собирался (14 октября 2026). Если очередная сборка остановится на ошибке компилятора, это нормально: текст ошибки пришлите, она исправляется за один заход. Шаг 7 говорит, что именно присылать.

## Что получится

`MemoryDesk.app`: обычное приложение со значком в Dock и в строке меню. Внутри окно с тем же интерфейсом, что открывается в браузере. Приложение само запускает сервер Memory Desk при открытии и останавливает его при выходе (сервер, который вы запустили из Терминала, оно не трогает). Приложение **не заменяет** установленную папку программы: оно запускает её `meeting-assistant`, поэтому папка и `install.command` нужны по-прежнему.

## Что нужно заранее

- Mac на Apple Silicon с macOS 13 или новее.
- Memory Desk уже установлен и запускается: `start.command` открывает интерфейс на `http://127.0.0.1:8502`. Если нет, сначала `./install.command` в папке программы.
- Средства разработчика Apple. Полный Xcode не обязателен, хватит Command Line Tools.

## Шаг 1. Проверьте, что есть Swift

Откройте Терминал и выполните:

```
swift --version
```

- Видите строку вроде `Apple Swift version 5.9` (или выше): переходите к шагу 2.
- Приходит предложение установить средства разработчика, либо `swift: command not found`: выполните `xcode-select --install`, согласитесь в окне, дождитесь конца установки и повторите `swift --version`.
- Версия ниже 5.9: обновите Command Line Tools (Системные настройки → Основные → Обновление ПО) или поставьте Xcode из App Store.

## Шаг 2. Перейдите в папку программы

Это та папка, где лежат `meeting-assistant`, `start.command` и папка `macos`:

```
cd ~/путь/к/папке/программы
ls macos
```

Должны быть `Package.swift`, `Sources`, `Resources`, `build_app.sh`. Если папки `macos` нет, обновите код: `git pull` или заново распакуйте свежий архив.

## Шаг 3. Соберите приложение

```
cd macos
chmod +x build_app.sh
./build_app.sh 2>&1 | tee ~/memorydesk-build.log
```

Скрипт собирает пакет (`swift build -c release`), складывает его в `build/MemoryDesk.app`, подставляет номер версии в `Info.plist` и подписывает приложение подписью «ad hoc» (для запуска на этом же Mac этого достаточно). Первая сборка занимает 1–3 минуты.

Успех выглядит так: в конце строка `Готово: …/macos/build/MemoryDesk.app`. Если сборка остановилась, переходите к шагу 7.

## Шаг 4. Установите и откройте

```
cp -R build/MemoryDesk.app /Applications/
xattr -dr com.apple.quarantine /Applications/MemoryDesk.app
open /Applications/MemoryDesk.app
```

Вторая команда снимает отметку «скачано из интернета»; она нужна, только если вы копировали приложение откуда-то, а не собирали у себя. Если macOS всё равно пишет, что приложение от неустановленного разработчика, нажмите на нём правой кнопкой → «Открыть» → «Открыть» (так нужно один раз: приложение не нотаризовано).

## Шаг 5. Первый запуск

1. Приложение спросит **папку программы**: выберите ту, где лежит `meeting-assistant`. Выбор запоминается.
2. macOS может спросить, разрешить ли приложению доступ к папке «Документы» (или другой, где лежит программа и ваш архив). Разрешите: без этого сервер не прочитает свои файлы.
3. Через несколько секунд появится окно с интерфейсом. Если открыто пустое окно или сообщение об ошибке, посмотрите `logs/app.log` в папке программы.

## Шаг 6. Проверьте по списку

Короткая проверка, что всё работает:

1. Закрыли окно красным крестиком: значок остался в строке меню, сервер работает. Клик по значку в Dock возвращает окно.
2. «Выйти» из меню значка: в Терминале `lsof -i :8502` ничего не показывает (сервер остановлен).
3. Запустили `start.command`, затем открыли приложение: оно подключилось к уже работающему серверу. При выходе из приложения этот сервер остался работать.
4. В полях ввода работают ⌘C, ⌘V, ⌘A, ⌘Z.
5. Ссылка на внешний сайт открывается в браузере, «Открыть в Obsidian» открывает Obsidian.
6. Скачивание документа (PDF или Word из записи) кладёт файл в «Загрузки».
7. Кнопка выбора файла для вложения открывает системный диалог.
8. В Терминале `open memorydesk://scan` запускает обработку новых записей (если включён PIN, открывает окно с запросом PIN).
9. Во время обработки записи значок в строке меню показывает, что она идёт.

Полный список с пояснениями: `README.md` в этой же папке. Быстрые команды macOS на основе адреса `memorydesk://` описаны в `SHORTCUTS.md`.

## Шаг 7. Если что-то не получилось

Пришлите мне:

- содержимое `~/memorydesk-build.log` (если не собралось); обычно достаточно строк с `error:`;
- вывод `swift --version` и `sw_vers`;
- если собралось, но не запускается: последние 40 строк `logs/app.log` из папки программы и что именно видно на экране.

Типичные причины:

| Что видите | Что делать |
|---|---|
| `swift: command not found` | шаг 1, `xcode-select --install` |
| `error: … requires macOS 13` или версия Swift ниже 5.9 | обновить macOS или Command Line Tools |
| `error:` с именем файла `.swift` | ошибка в коде оболочки: пришлите лог, я исправлю |
| `codesign: … resource fork, Finder information` | выполнить `xattr -cr build/MemoryDesk.app` и повторить подпись: `codesign --force --deep --sign - build/MemoryDesk.app` |
| «Приложение повреждено» или «от неустановленного разработчика» | `xattr -dr com.apple.quarantine /Applications/MemoryDesk.app`, затем правый клик → «Открыть» |
| Окно пустое, сервер не стартует | проверить, что `start.command` в той же папке запускается из Терминала; посмотреть `logs/app.log` |
| Папку программы не принимает | нужна именно папка, где лежит файл `meeting-assistant` (не `macos` и не `memory_desk`) |
| Порт 8502 занят | другой процесс уже слушает порт; `lsof -i :8502` покажет какой |

## Шаг 8 (по желанию). Запуск при входе в систему

Системные настройки → Основные → Объекты входа → «+» → выберите `MemoryDesk`. Приложение откроется вместе с компьютером и будет ждать в строке меню; для окна достаточно кликнуть по значку.

## Как собирать заново после обновления кода

Обновили папку программы (новая версия Memory Desk), приложению пересобираться не нужно: оно запускает код из папки. Пересобрать его надо, только если изменилась папка `macos/`: повторите шаги 3 и 4 (`cp -R` заменит приложение, перед этим выйдите из него).

## Чего в приложении пока нет

Подписи Developer ID и нотаризации (нужна платная учётная запись Apple Developer), автообновления, собственного значка `.icns`, App Intents для «Быстрых команд», быстрой заметки и закладки из строки меню. Установка с нуля без Терминала тоже пока на `install.command` или `scripts/bootstrap.sh`.
