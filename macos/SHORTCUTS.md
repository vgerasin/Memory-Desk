# Быстрые команды macOS (11.3)

Нативных действий App Intents в этой версии нет: они собираются только в Xcode с расширением метаданных, а здесь Xcode нет. Те же сценарии работают через приложение «Быстрые команды» — через адрес `memorydesk://` и «Выполнить скрипт оболочки».

| Команда | Как собрать в «Быстрых командах» |
|---|---|
| Открыть Memory Desk | действие «Открыть URL»: `memorydesk://open` |
| Записи за сегодня | «Открыть URL»: `memorydesk://today` (окно открывается на «Сегодня», это первый экран) |
| Обработать новые записи | «Открыть URL»: `memorydesk://scan` |
| То же без окна | «Выполнить скрипт оболочки»: `curl -fsS -X POST -H 'X-Memory-Desk: 1' http://127.0.0.1:8502/api/jobs/scan` |
| Сколько ждёт внимания | «Выполнить скрипт оболочки»: `curl -fsS http://127.0.0.1:8502/api/state` → «Получить значение словаря» `inboxCount` → «Показать уведомление» |

Запуск по расписанию — «Автоматизация» в «Быстрых командах» (например, каждый день в 9:00 — `memorydesk://scan`); горячая клавиша — в свойствах команды; Spotlight показывает команды сам.

**Если включён PIN:** сервер отвечает на такие запросы кодом 423 (заблокировано), и команда с `curl` ничего не сделает. Команды через `memorydesk://` в этом случае открывают окно, чтобы ввести PIN. Это сознательно: PIN кабинета не должен обходиться скриптом без ключа. Для скриптов без окна понадобятся отдельные ключи (этап 8, пропущен).

Команды «Спросить архив» и «Добавить заметку к записи» требуют аргументов и ответа в «Быстрых командах»; без App Intents их не сделать честно, поэтому они остаются в плане.
