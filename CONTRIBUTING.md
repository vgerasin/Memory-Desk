# Как помочь проекту

Memory Desk — локальный кабинет встреч, всё работает на вашем компьютере. Идеи, сообщения об ошибках и правки приветствуются.

## Сообщить об ошибке или предложить идею

Откройте [issue](https://github.com/vgerasin/Memory-Desk/issues/new/choose) по шаблону. Для ошибки пригодятся: версия (внизу «Настроек»), macOS и чип, что делали, что ожидали, что получили, и раздел «Настройки → Данные → Проверка системы». **Не прикладывайте записи, стенограммы и заметки с чужими данными**: достаточно описания.

Об уязвимостях пишите не в открытый issue, а так, как описано в [SECURITY.md](SECURITY.md).

## Предложить изменение

1. Сделайте форк, ветку от `main`.
2. Установите окружение: `./install.command --skip-models` (или `pip install -r requirements-ci.txt`).
3. Проверьте: `python -m pytest -q` (все тесты должны проходить).
4. Если трогали интерфейс: `cd frontend && npm install && npm run build`. Сборка кладётся в `memory_desk/web` и коммитится; CI падает, если она расходится с исходниками.
5. Откройте pull request: что изменено и зачем, что проверено.

## Правила, о которых тесты напомнят

- Тексты интерфейса пишутся по-русски внутри `tr()`; переводы (en, fr, de, es) лежат в `frontend/src/locales/`, в них нет кириллицы.
- Каждый изменяющий маршрут `/api` попадает в журнал (`audit.ACTIONS` или `audit.READ_ONLY`).
- Всё локально: ничего не отправляется в сеть без явного действия человека.
- В тестах не импортируют `memory_desk.*` на уровне модуля.

Подробнее об устройстве: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), о планах: [docs/ROADMAP.md](docs/ROADMAP.md).
