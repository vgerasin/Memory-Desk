# Memory Desk 3.0.0 — языки, телефон, заготовка приложения macOS

Подробный список — в [CHANGELOG](../../CHANGELOG.md). README теперь на русском, [английском](../../README.en.md) и [французском](../../README.fr.md).

## Главное

- **Языки интерфейса:** русский, английский, французский, немецкий, испанский. Переключение без перезапуска; даты, числа и склонения по правилам языка; слово-подтверждение стирания на языке интерфейса. Заметки, стенограммы и подсказки модели остаются на русском. **Переводы — машинный черновик, нужна вычитка носителем.**
- **Чтение с телефона по домашней сети.** Выключено по умолчанию. Отдельный второй сервер только для чтения (кабинет по-прежнему слушает только `127.0.0.1`): «Сегодня», записи с поиском, запись, задачи и решения, люди и проекты. Вход по PIN, свой токен у каждого телефона (1, 7 или 30 дней), отзыв по одному и всех сразу, после 10 неверных PIN подряд режим выключается сам. Только адреса домашней сети, защита от прокси, DNS-rebinding и CSRF; стенограмма на телефон по отдельному переключателю; в журнале исполнитель «Телефон». Разбор угроз: [REMOTE-THREATS.md](../REMOTE-THREATS.md). Чат с телефона сознательно не включён.
- **Приложение macOS — только черновик** ([`macos/`](../../macos/README.md)): окно, запуск и остановка своего сервера, значок в строке меню, адрес `memorydesk://`, сборка `.app`; рецепты «Быстрых команд». **Не собиралось и не запускалось** (в среде разработки нет Swift и Xcode). Подпись, нотаризация, автообновление и App Intents не сделаны.

## Что не проверено на реальном Mac

Всё из перечисленного выше про оболочку macOS; адрес компьютера в вашей сети и запрос брандмауэра при включении доступа с телефона; https с сертификатом `mkcert`; показ русских заметок рядом с переведённым интерфейсом на ваших данных. Ограничения — в [STATUS.md](../STATUS.md).
