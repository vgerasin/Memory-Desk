# Memory Desk 2.4.0 — предложения после встречи и живое досье

Подробный список — в [CHANGELOG](../../CHANGELOG.md).

## Главное

- **Предложения действий после встречи.** Договорённости из стенограммы («созвонимся в четверг в 15:00», «отправь Ивану протокол», «напомни до пятницы») показываются карточками с цитатой и таймкодом. Событие в Календаре, напоминание или черновик письма создаются **только по вашему нажатию**; даты разрешает код, а не модель; неоднозначное уходит в «Изменить».
- **Живое досье человека и проекта.** Закреплённые факты (не затираются при обновлении), висящие вопросы по всем записям, абзац «о чём разговор» (локальная модель только по пунктам кратких содержаний, с запасным вариантом без модели), «что принесли последние записи». Стирание записи убирает из досье всё, что взято из неё.

Версия в самом коде (`__version__`) в этом снимке ещё 2.1.0: номер поднят начиная с 3.0.0.

## Не вошло

Локальный MCP-сервер и командная строка (этап 8) сознательно пропущены и остаются в плане.

## Что не проверено на реальном Mac

Качество извлечения договорённостей настоящей `qwen3:4b`, создание событий и напоминаний через EventKit, черновик письма через «Почту». Ограничения — в [STATUS.md](../STATUS.md).
