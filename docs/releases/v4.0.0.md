# Memory Desk 4.0.0 — сокращение, MCP и командная строка, мастер установки

Подробный список — в [CHANGELOG](../../CHANGELOG.md). Номер основной, потому что часть функций убрана. Данные и настройки совместимы: схема базы и формат заметок не менялись.

## Главное

- **Мастер первого запуска и установки.** Четыре шага: проверка системы, модели, папки и доступы, итог. Недостающее докачивается по кнопке с размером, этапами, скоростью и оставшимся временем. Системное окно выбора папки, блок «Где что лежит». Открывается само на чистой установке; повторить можно в «Настройки → Данные → Проверка системы».
- **Два пути установки.** Браузерный: клонировать репозиторий и запустить `install.command`. Приложение для Mac: окно установки скачивает проект и запускает установщик; модели докачивает мастер.
- **Командная строка и MCP-сервер.** `./memory-desk ask | search | list | ingest | status | mcp`. Вход только по токену из «Настроек → Безопасность → Доступ для программ» (чтение; запись включается отдельно, отзыв в один клик). Каждое обращение попадает в журнал действий.
- **Правка стенограммы в кабинете** и **выбор модели анализа** из скачанных в Ollama.
- **Приложение как приложение.** Шапка на месте, прокручивается только содержимое, обычные для программы выделение и курсор; значок приложения.
- **Настройки по вкладкам** вместо одной длинной прокрутки.

## Убрано

Доступ с телефона, экран «Календарь» (события Календаря macOS остаются на «Сегодня» и в записи), выгрузка карты в SVG и OPML (остался PNG), презентации `.pptx`, вкладка «Взгляды» (пять готовых фокусов стали шаблонами заметки).

## Что не проверено на реальном Mac

Настоящие загрузки моделей из мастера и `brew install`, окно установки в приложении на «чистом» Mac, подключение настоящего Claude Desktop к MCP, строка меню и быстрые команды. Приложение собирается и открывается.
