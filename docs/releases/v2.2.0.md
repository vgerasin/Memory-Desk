# Memory Desk 2.2.0 — шаблоны, взгляды, закладки, оформление

Локальный AI-кабинет встреч: аудио, стенограммы и заметки не покидают компьютер. Подробный список — в [CHANGELOG](../../CHANGELOG.md).

## Главное

- **Шаблоны заметки.** «Совещание с решениями», «Планёрка», «Встреча один на один», «Интервью», «Лекция»; шаблон выбирается до обработки, у готовой записи — «Пересобрать по другому» (подтверждённые задачи и решения переносятся, прежняя заметка сохраняется). Свой шаблон можно составить по описанию.
- **Взгляды на запись.** «Только решения», «Задачи по людям», «Вопросы к заказчику», «Риски», «Для руководителя на 5 строк» или свой; основной текст они не меняют.
- **Закладки** на записи (клавиша B): живут в самой заметке, находятся поиском.
- **Ответы чата** сохраняются в Obsidian с источниками; под ответом подсказки, что спросить дальше.
- **Утренняя сводка** и уведомление о готовой записи; **зависшие задачи**; **серии встреч**; предупреждение, когда новое решение расходится со старым; ход составления протокола.
- **Словарь терминов** (исправляет расшифровку: «кахэде» → «КХД»), **резервные копии по расписанию**.
- **Оформление:** пять тем, у каждой светлый и тёмный режим.
- `Проверка этапа 0.command` — отчёт о проверке на реальном Mac без текстов записей.

Версия в самом коде (`__version__`) в этом снимке ещё 2.1.0: номер поднят начиная с 3.0.0.

## Что не проверено на реальном Mac

Расшифровка MLX Whisper и анализ Ollama через новый интерфейс, качество `qwen3:4b` на шаблонах и взглядах, EventKit, установка на «чистый» Mac. Ограничения — в [STATUS.md](../STATUS.md). Первый запуск стоит пройти на одном коротком файле.
